# TECHNICAL_SPEC.md

## Project Overview
This project aims to develop the core backend MVP for NutriTrack, an AI nutrition coaching SaaS. The focus is on delivering essential features for initial user testing and launch, supporting the goal of acquiring 500 paying users in 90 days.

## Tech Stack
*   **Language:** Python 3.9+
*   **Web Framework:** FastAPI
*   **Data Validation:** Pydantic
*   **ORM:** SQLAlchemy
*   **Database:** PostgreSQL
*   **Containerization:** Docker
