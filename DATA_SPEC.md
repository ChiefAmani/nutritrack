# DATA_SPEC.md

## Project: NutriTrack User Acquisition & Engagement Tracking

## Sheet Name: User_Metrics

## Column Headers:
- Metric_Name: (String) Name of the KPI.
- Description: (String) Detailed explanation of the metric.
- Data_Type: (String) Expected data type (e.g., 'Integer', 'Float', 'Date', 'Boolean').
- Source_System: (String) Where the data originates (e.g., 'NutriTrack Backend', 'Stripe', 'Google Analytics').
- Calculation_Method: (String) How the metric is calculated or defined.
- Target_Value_90_Days: (String) The target value for the metric within the 90-day goal (if applicable).
- Reporting_Frequency: (String) How often the metric should be reported (e.g., 'Daily', 'Weekly', 'Monthly').
